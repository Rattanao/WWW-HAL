Import D/O tool · DEM / power charge start dates

DO

Adds the demurrage start date, the power charge start date and SPECIAL CONTAINER to the bottom of every page of a Cargo Delivery Order in one go. Dates come from CHECK DEM or are typed in, and you get files ready to print in 2 sets.

DO.pdf+ CHECK DEM.xlsx→ DO-DEM.pdf+ DO-DEM-PRINT x 2.pdf
Use online (no install) Download the program (ZIP) Open on GitHub

Use online

Nothing to install. Files are processed in the browser of the computer you are using and are not uploaded anywhere

  1. Drag in the DO file (.pdf); one or more files, which the page joins in order

    CHECK DEM.xlsx is optional. Without it, fill in DEM. date and/or Power charge date yourself

  2. Click Process

    The table shows what is added on each page. A red date cell = no date yet. You can edit dates per B/L in the table, then click Process again

  3. Click Download DO-DEM.pdf (x1 + x2) or Print x2

    You get 2 files in your Downloads folder: DO-DEM.pdf (one set) and DO-DEM-PRINT x 2.pdf (in print order). The first time, the browser may ask to “allow multiple downloads”; click Allow

First-time setup

Once per computer, Windows (skip this if you use the online tool)

  1. Install Python 3 from python.org/downloads

    On the installer's first screen tick ☑ Add python.exe to PATH before clicking Install Now

  2. Download the program with the “Download the program (ZIP)” button above

    Right-click the ZIP → Extract All, and keep the folder anywhere, e.g. Documents

  3. The first run needs an internet connection

    The program installs the libraries it needs (pymupdf, openpyxl) automatically and uses the Angsana New font that comes with Windows

Every job (desktop program)

  1. Put the files in the input folder

    The D/O file whose name starts with DO, e.g. DO-SWSR.pdf, and CHECK DEM.xlsx (from Check-dem)

  2. Double-click run-do.bat

    The black window shows what is added on each page. Pages without a date show ** ไม่มีวันที่ DEM ใน CHECK DEM ** (no DEM date in CHECK DEM)

  3. Open the results at output\DO-DEM.pdf and output\DO-DEM-PRINT x 2.pdf

    Files in input are not changed. If a result file is open, close it before running again

Where the dates come from

  • DEM = the DEM. cell for that B/L in CHECK DEM
  • Power = the REC. cell; if empty, ATA + 3 days
  • A house B/L such as ...038A that isn't in CHECK DEM uses the date of its master B/L ...038
  • On the web: dates edited in the table > CHECK DEM > the date boxes at the top

Print x2

  • One B/L = its D/O page + its ATTACHED RIDER page
  • CY: each B/L twice in a row, e.g. 1, 1, 2, 2
  • CFS: 2 sets per master B/L, e.g. 038, 038A, 038B, 038, 038A, 038B
  • If you load an already-filled file again, filled pages are skipped, never filled twice
