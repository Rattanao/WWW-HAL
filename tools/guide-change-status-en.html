MMAN EDI file tool · Import customs declaration

Change Status → MMAN

Fills in POL, SHED NO. and country code, and changes the container STATUS in the MMAN file from the job's B/L list. You get MMAN_EDI.txt with every line the same length as before, ready to send on.

MMAN_*.txt+ SUR.xls→ MMAN_EDI.txt
Use online (no install) Download the program (ZIP) Open on GitHub

Use online

Fastest, nothing to install. Files are processed in your browser only and are never uploaded to a server.

  1. Open the online tool and choose the MMAN file (.txt)

  2. Choose the STATUS list (.xls / .xlsx / .csv)

  3. Start B/L … End B/L (only if you want to cut the file)

    Keeps the PSKV line, then keeps only the B/Ls in this range (including sub-B/Ls …A, …B and their container lines); everything else is cut · Start left empty = from the first B/L · End left empty = to the last line · Both empty = no cut

  4. Check SHED NO. Left box = B/Ls that have a Status, right box = all other B/Ls

    Defaults 0145 / 0122, change them to suit the job · Jobs with no Status (e.g. LCH): enter SHED NO. in the left box and clear the right box = the same value for every B/L

  5. Click Change, review the summary, then click Download MMAN_EDI.txt

    The file is saved to your Downloads folder · If the page still looks old, press Ctrl + F5

First-time setup (desktop program)

Once per computer, Windows · If you only use the online tool, skip this section

  1. Install Python 3 from python.org/downloads

    On the installer's first screen tick ☑ Add python.exe to PATH before clicking Install Now

  2. Download the program with the “Download the program (ZIP)” button above

    Right-click the ZIP → Extract All, and keep the folder anywhere, e.g. Documents

  3. The first run needs an internet connection

    The program installs the libraries it needs (pandas, xlrd, openpyxl) automatically

Every job

  1. Put the files in the input folder

    Remove the previous job's files first, then add one MMAN file (.txt) and one STATUS list (.xls/.xlsx/.csv). An old MMAN_EDI.txt left there is not counted as a source file

  2. Double-click run-change-status.bat

  3. Type the SHED NO. and press Enter twice

    It asks for two values: B/Ls with a Status and all other B/Ls. Press Enter to skip and use 0145 and 0122 · Type = for the second value = use the first value for every B/L (LCH jobs)

  4. Open the result at output\MMAN_EDI.txt

    The black window summarises the number of B/Ls, Status changes and PG→PX. If you see a WARNING line, read it before using the file

STATUS list (Excel)

Only columns A–C are used, with the header in the first row; ignore columns D–F. The program finds the columns by their header names, so both forms work

Illustration only, B/L numbers shortened

  • B/L No.: the master B/L number, which also covers its sub-B/Ls (…462A, …462B)
  • Status: e.g. 9 N, 7 N; any number of spaces works (7 N, 7N), the program puts it in the right position · Empty = keep the original Status
  • POL: 5 letters, e.g. KRPUS, CNSHA

What changes in the MMAN file

Only the defined positions are edited; file size and line endings stay identical byte for byte

AfterHASLK01260700462                   KRPUSTHBKKTHBKK0145GOLDWAY…   KR   …   O ACRYLONITRILE…
BeforeSKHU9545854      8  N   1        Y

#PositionValue written
1col 36–40POL from the list, e.g. KRPUS
2col 41–45The port of most B/Ls in the file (THBKK or THLCH), e.g. CNTAOTHLCHTHLKR0332
3col 46–50Port as in the original (THBKK, THLCH, THLKR, …), not changed
4col 51–54SHED NO., locked by the original port: BMT 0110 · SCT 0302 · LKR 0332 · UCT 0113 · LCH with DG (has UN/CLASS) 2826 · BKK going to LAOS 0124 · Other BKK and LCH B/Ls use the SHED NO. boxes (0145 if the B/L has a Status, 0122 for the rest · right box empty = use the left value)
5col 844–845First 2 letters of the POL in place of TH (KR, CN)
6Container lineStatus from the list, e.g. 8  N → 9  N
PXPackage unitPG → PX on every B/L
Ncol 881 · 974 · 1765Consignee name and notify name = always the notify name at col 1672 (TH + name), single-spaced, on every B/L (BKK and LCH) · The address after the name is kept · Except TRANSIT/TRANSHIPMENT, which are left unchanged
Tcol 1670 · 3804TRANSIT/TRANSHIPMENT: the TH before the notify name = destination country (LA, MM, KH, CN, PG, MY) · Letter before the description: TRANSIT = 7, TRANSIT to LAOS = per CARGO MOVEMENT (L / 7), TRANSHIPMENT = 3
−col 1742 · 1416 · 2207Every B/L except TRANSIT/TRANSHIPMENT: clears the notify tax ID and the consignee / notify addresses (the consignee tax ID and branch code are kept)

Always kept

  • The letter O before the description (except TRANSIT/TRANSHIPMENT)
  • Names on TRANSIT/TRANSHIPMENT B/Ls
  • The Status of B/Ls whose Status cell is empty
  • B/Ls not in the list (you get a warning)
  • The source files in input are never edited

Check the summary every time

  • Number of B/Ls changed matches the list
  • Number of SHED 0145 / 0122
  • Status changes and number of container lines
  • B/Ls changed PG → PX
  • File size equals the original
