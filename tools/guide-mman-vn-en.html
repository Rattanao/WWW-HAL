MMAN — Cut B/Ls + Change Status

Cuts an MMAN file down to the B/Ls you want (or no cut), then fills in POL, SHED NO., country code, consignee / notify names and changes the container STATUS from the job's B/L list. You get a file named by the POD (MMAN_LCH.txt / MMAN_BKK.txt / MMAN_UCT.txt) with every line the same length as before, ready to send

MMAN_*.txt+ SUR.xls→ MMAN_<POD>.txt
Use online (no install) Download the program (ZIP) Open on GitHub

Use online

Fastest, nothing to install. Files are processed in your browser only and are never uploaded to a server

  1. Open the online page and choose the MMAN file (.txt)

  2. Choose the STATUS list (.xls / .xlsx / .csv)

  3. Keep from B/L … To B/L (if you want to cut the file)

    Keeps the PSKV line, then only the B/Ls in this range (with sub-B/Ls …A, …B and container lines); the rest is cut · first box empty = from the first B/L · second box empty = to the last line · both empty = no cut

  4. Choose the POD, then check SHED NO.: left box = B/Ls with a Status, right box = other B/Ls

    Choosing the POD fills in the SHED: THLCH 2813 for every B/L (right box empty) · THBKK 0145 / 0122 · THUCT every B/L becomes THUCTTHUCT with SHED 0113 · you can edit the numbers · right box empty = the left box for every B/L

  5. Click Cut + Change status, check the summary, then click Download (file named by the POD, e.g. MMAN_BKK.txt)

    If the page still looks old, press Ctrl + F5

First-time install (program on your computer)

Once per computer, Windows · skip this if you only use the online page

  1. Install Python 3 from python.org/downloads

    On the installer's first screen tick ☑ Add python.exe to PATH before clicking Install Now

  2. Download the program with the “Download the program (ZIP)” button above

    Right-click the ZIP → Extract All, and keep the folder anywhere, e.g. Documents

  3. The first run needs internet

    The program installs the libraries it needs (pandas, xlrd, openpyxl) by itself

Every time

  1. Put the files in the input folder

    Delete the old job's files first, then put in one MMAN file (.txt) and one STATUS list (.xls/.xlsx/.csv). The result goes to the output folder

  2. Double-click run-mman.bat

  3. Answer the questions in the black window; press Enter to skip any of them

    Keep from B/L / To B/L (Enter on both = no cut) · POD THLCH / THBKK / THUCT (Enter = THLCH) · SHED NO. for B/Ls with a Status and for other B/Ls (Enter = the POD's values: THLCH 2813 · THBKK 0145 / 0122) · type = for other B/Ls = same as the first box

  4. Open the result output\MMAN_LCH.txt (or MMAN_BKK.txt / MMAN_UCT.txt by POD)

    The black window sums up the B/Ls, the Status changes and PG→PX. Read any WARNING line before using the file

Only columns A–C are used, with the headings on the first row; columns D–F do not matter. The program finds the columns by heading, so both forms work

Examples only; B/L numbers shortened

  • B/L No.: the master B/L number; it covers its sub-B/Ls too (…462A, …462B)
  • Status, e.g. 9 N, 7 N, with any number of spaces (7 N, 7N); the program puts it in the right place · empty = Status unchanged
  • POL: 5 letters, e.g. KRPUS, CNSHA

What changes in the MMAN file

Only the given positions change; the file size and line breaks stay byte for byte

#PositionValue written
1col 36–40POL from the list, e.g. KRPUS
2col 41–45The port most B/Ls in the file have (THBKK or THLCH), e.g. CNTAOTHLCHTHLKR0332
3col 46–50The original port (THBKK, THLCH, THLKR, …), not changed
PODcol 41–50POD THUCT (the file comes as THBKK) = every B/L becomes THUCTTHUCT with SHED 0113 · THLCH / THBKK = as in 2–3 (fixed)
4col 51–54SHED NO. fixed by original port: BMT 0110 · SCT 0302 · LKR 0332 · UCT 0113 · LCH DG (with UN/CLASS) 2826 · BKK to LAOS 0124 · other BKK and LCH from the SHED NO. boxes (left = B/Ls with a Status, right = other B/Ls · POD values: THLCH 2813 · THBKK 0145 / 0122 · right box empty = the left box)
5col 844–845First 2 letters of the POL in place of TH (KR, CN)
6container linesStatus from the list, e.g. 8  N → 9  N
PXpackage unitPG → PX on every B/L
5col 3804The O before the description → 5 only on B/Ls with Status 9  N · other B/Ls keep O · except TRANSIT/TRANSHIPMENT, which use 7 / 3 / L
Ncol 881 · 974 · 1765Consignee and notify names = the notify name at col 1672 (TH + name), always single-spaced, on every B/L (BKK and LCH) · the address after the name stays · except TRANSIT/TRANSHIPMENT, never changed
Tcol 1670 · 3804TRANSIT/TRANSHIPMENT: the TH before the notify name = destination country (LA, MM, KH, CN, PG, MY) · the letter before the description: TRANSIT = 7, TRANSIT to LAOS = per CARGO MOVEMENT (L / 7), TRANSHIPMENT = 3
−col 1742 · 1416 · 2207Every B/L except TRANSIT/TRANSHIPMENT: clears the notify tax ID and the consignee / notify addresses (the consignee tax ID and branch code stay)

Always unchanged

  • The O before the description (except TRANSIT/TRANSHIPMENT)
  • Names on TRANSIT/TRANSHIPMENT B/Ls
  • The Status of B/Ls whose Status cell is empty
  • B/Ls not in the list (you get a warning)
  • The source file in input is never changed

Summary to check every time

  • The number of B/Ls changed matches the list
  • The number of B/Ls per SHED
  • The Status changes and the number of container lines
  • The B/Ls changed PG → PX
  • The number of lines cut and the B/L range kept
