Bayplan HUL

เก็บเฉพาะตู้ HUL จากไฟล์ Bayplan (.asc) ของท่าที่เลือก (LCH / BKK) เปลี่ยน agent HAL / HAC / HAS เป็น HUL และลด TEMP ของตู้ RF ทำงานในเบราว์เซอร์ ไม่มีการอัปโหลดไฟล์

KHS1_2612S_KRUSN_SWIC.asc→KHS1_2612S_KRUSN_SWIC_HUL_BKK-LCH.asc
ใช้งานออนไลน์ (ไม่ต้องติดตั้ง) เปิดหน้า GitHub

สิ่งที่โปรแกรมทำ

  • เก็บ ตู้ที่ agent เป็น HAL / HAC / HAS / HUL (แก้รายชื่อได้ในช่อง Agents changed to HUL) และท่าปลายทางเป็นท่าที่ติ๊กไว้ (LCH, BKK หรือทั้งสอง)
  • ตัดทิ้ง ตู้ agent อื่นทั้งหมด (SKR, KMD, EMC …) และตู้ของท่าอื่น (SGN …)
  • agent ของตู้ที่เก็บเปลี่ยนเป็น HUL
  • ตู้ RF ลด TEMP 1 ตำแหน่ง เช่น -250C → -25C
  • บรรทัดหัวไฟล์ และทุกบรรทัดตั้งแต่ ***Refer to the following remark. (remark, IMDG, VGM) คงเดิม
  • ชื่อไฟล์ที่ได้ = ชื่อไฟล์ต้นฉบับ + _HUL_ + ท่าที่เลือก เช่น _HUL_BKK-LCH.asc บันทึกลงโฟลเดอร์ Downloads

ข้อความ / อาการวิธีแก้
