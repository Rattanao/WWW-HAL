Check DEM

หาวันเริ่มเก็บค่า Demurrage (DEM.) และวันรับตู้ (REC.) ของทุก B/L จากช่อง Freedays และวันที่ ATA แล้วออกรายงาน CHECK DEM.xlsx แบบใส่สีตามวัน พร้อมพิมพ์ A4

DEM-*.xls (Freedays)+ ATA→ CHECK DEM.xlsx
ใช้งานออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ใช้งานบนเว็บ

  1. ลากไฟล์ Freedays มาวาง หรือคลิกเพื่อเลือกไฟล์ (.xls / .xlsx)

    ฟอร์มต้นฉบับมีได้หลายแบบ โปรแกรมหาหัวข้อจากชื่อ ไม่สนว่าอยู่คอลัมน์ไหน: Freedays, TPSZ, B/L No., RECEIPT B/L, Consignee

  2. เลือกวันที่ ATA แล้วกด คำนวณ

  3. ตรวจตารางบนหน้าจอ

    สีแยกตามวัน DEM. คลิกป้ายวันที่เพื่อซ่อน/แสดงวันนั้น และค้นหา B/L หรือ Consignee ได้

  4. กด ดาวน์โหลด CHECK DEM.xlsx แล้วเลือกโฟลเดอร์ที่จะบันทึก

    ไฟล์ถูกประมวลผลในเบราว์เซอร์เท่านั้น ไม่มีการอัปโหลดไปที่ใด · กด ลบไฟล์ เพื่อเริ่มงานใหม่

กติกาการคำนวณ

ช่องวิธีคิดตัวอย่าง (ATA 27/09/2026)
TOTALเลขตัวหน้าของ Freedays + เลขตัวหน้าหลังคำว่า Add7/5 Add 7/9 → 7 + 7 = 14
DEM.ATA + TOTAL วัน27/09/2026 + 14 = 11/10/2026
REC.ATA + 3 วัน เฉพาะแถวที่มี TOS หรือเป็นตู้เย็น (TPSZ ขึ้นต้นด้วย R)7/5 Add 7/9 TOS 3 → 30/09/2026

ตัวอย่างอื่น: 3/3 Add 2/11 = 5 วัน · 3/3 Add 9/4 = 12 วัน · 7/5 Add 14/2 = 21 วัน · ตู้เย็นถือเป็น TOS 3 เสมอเพราะมีค่าไฟ

อ่านรายงาน CHECK DEM.xlsx

คอลัมน์ No. | TPSZ | REC. | TOTAL | Freedays | DEM. | B/L No. | RECEIPT B/L | Consignee · ตั้งค่าพิมพ์ A4 แนวตั้ง พอดี 1 หน้ากว้าง

DEM. / Freedays สีเดียวกันวันเริ่มเก็บค่า DEM วันเดียวกัน สีไล่จากวันแรกสุด (แดง) ถึงวันหลังสุด (ฟ้า)
REC. พื้นส้มแถวที่มี TOS หรือเป็นตู้เย็น (Freedays ตัวหนาสีแดง)
RECEIPT B/L พื้นเหลืองตัวอักษรสีแดง ให้สังเกตง่าย
DEM. ขึ้น CHECKอ่าน Freedays ไม่ได้ ต้องตรวจเอง

ใช้แบบโปรแกรมในเครื่อง (Python)

  1. ติดตั้ง Python 3.9+ จาก python.org/downloads แล้วดาวน์โหลด ZIP ด้านบน แตกไฟล์ไว้

    ครั้งแรกรัน pip install -r requirements.txt

  2. วางไฟล์ต้นฉบับในโฟลเดอร์ input แล้วดับเบิลคลิก run_check_dem.bat

  3. พิมพ์วันที่ ATA เช่น 27/09/2026 แล้วเปิดผลที่ output\CHECK DEM.xlsx

ถ้าเจอปัญหา

ข้อความ / อาการวิธีแก้
DEM. ขึ้นคำว่า CHECKช่อง Freedays เขียนรูปแบบที่อ่านไม่ได้ ให้ตรวจและคำนวณแถวนั้นเอง
ปุ่มคำนวณกดไม่ได้ต้องเลือกทั้งไฟล์และวันที่ ATA ก่อน
ไม่พบหัวข้อ Freedaysตรวจว่าไฟล์มีหัวคอลัมน์ชื่อ Freedays อยู่จริง

รายงานนี้เป็นตัวช่วยคำนวณ ควรตรวจแถวที่เป็นสีแดงหรือขึ้น CHECK ทุกครั้ง
