EDI file tool · Reefer CLIST

Revised Temp

Fixes reefer temperatures in a CLIST file (.txt) by removing the last digit before C, then saves it as Revised temp.txt with an Excel report.

CLIST*.txt→ Revised temp.txt+ Revised temp.xlsx
Use online (no install) Download the program (ZIP) Open on GitHub

Use on the web

  1. Drag the CLIST file into the dashed box, or click to choose it

  2. Click แก้ไขอุณหภูมิ (Fix temperature)

  3. Check the results table (line, container no., Size/Type, old and new value)

    Click "ไม่แก้ไข … บรรทัด" (… lines not changed) to see containers that were left as they are, with the reason

  4. Click บันทึก Revised temp.txt (Save), and for the report click ดาวน์โหลด Excel (Download Excel). Files are saved to your Downloads folder

    The file is read and changed in the browser only · Click ลบไฟล์ (Clear files) to start a new job

Rules

OldNewNote
S-20CS-2CLast digit before C removed
S-180CS-18C
S50CS5C
S0CS0CNot changed: only one digit
SSNot changed: no digits
  • The temperature field is at character 145 of each line (right after Size/Type, e.g. 45R1 8 Q)
  • The removed character is replaced with a space, so every line keeps its length and the following columns stay in place
  • Nothing else in the file is changed, including line endings (CRLF)

The Revised temp.xlsx report

Formatted to print on A4 portrait, with 2 sheets

ผลการแก้ไข (Changes)Report header, old values (struck through) and new values (green), with a count per temperature
ไม่แก้ไข (Not changed)Containers whose temperature is S0C or S, with the reason

Use the desktop program (Python)

Needs Python 3.8 or later. The result is saved as Revised temp.txt in the same folder as the source file

python revised_temp.py "CLISTHLCH_xxxx.txt"

Troubleshooting

Message / symptomFix
No lines were changedCheck it is a CLIST file with reefer containers and the temperature is at position 145
Some containers were not changedSee the "Not changed" list: S0C and S need no change under the rules
