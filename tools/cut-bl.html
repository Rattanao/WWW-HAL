Mode 1, cut a range: deletes from the H02 line of the start B/L to the last line (H03 … H10) of the end B/L (including sub-B/Ls …A, …B), keeping the rest · start empty = from the first H02 · end empty = to the last line · Mode 2, keep only these B/Ls: enter one or more B/Ls to keep, separated by , or new lines (e.g. HASLJ01260800588,HASLK02261000346), with their sub-B/Ls; every other B/L is cut · one mode at a time · all boxes empty = no cut · Every B/L left: H05 = the same name as H06, single-spaced only (H06 unchanged), except TRANSIT / TRANSHIPMENT B/Ls (including INTRANSIT), whose H05 / H06 are never changed · H07 package unit PG → PX · the HOU / H01 header lines are always kept (without them the ECS program says invalid MMAN Text File) · type HASLC… or H02HASLC… · output file name = the source file name before "__" plus _PORTAL, e.g. KMGY_2608S_PORTAL.txt · processed in your browser, no file upload
