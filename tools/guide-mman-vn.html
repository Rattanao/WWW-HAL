เครื่องมือแก้ไฟล์ EDI · MMAN

MMAN VN

ตัดไฟล์ MMAN EDI ให้เหลือเฉพาะช่วง B/L ที่ต้องการ แล้วทำ Change status ต่อในขั้นตอนเดียว ได้ไฟล์ MMAN_VN.txt พร้อมส่ง

MMAN_*.txt+ STATUS .xls/.csv+ ช่วง B/L→ MMAN_VN.txt
ใช้งานออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ไฟล์ที่ต้องเตรียม

  1. MMAN — MMAN_*.txt 1 ไฟล์

  2. รายการ Status — .xls / .xlsx / .csv ใช้คอลัมน์ A-C ที่มีหัว B/L No., Status, POL (เรียงแบบไหนก็ได้)

    B/L No. ใส่เลขหลัก เช่น HASLS21260801066 จะครอบคลุม sub-B/L (…066A, …066B) ด้วย · Status เช่น 9 N เว้นว่าง = คงเดิม

  3. เริ่มต้นเก็บ B/L / ถึง B/L — B/L แรกและ B/L สุดท้ายที่ต้องการให้เหลือในไฟล์

ใช้งานบนเว็บ

  1. เลือกไฟล์ MMAN (.txt) และ ไฟล์ STATUS

  2. พิมพ์ เริ่มต้นเก็บ B/L และ ถึง B/L

    เว้นว่าง "เริ่มต้น" = ตั้งแต่ B/L แรก · เว้นว่าง "ถึง" = ถึงบรรทัดสุดท้าย · เว้นว่างทั้งคู่ = ไม่ตัด ทำ Change status อย่างเดียว

  3. แก้ SHED NO. ถ้าต้องการ (ค่าเริ่มต้น 0145 สำหรับ B/L ที่มี Status / 0122 ที่เหลือ)

  4. กด ตัด + Change status ตรวจผลในตาราง แล้วกด ดาวน์โหลด MMAN_VN.txt และเลือกโฟลเดอร์ที่จะบันทึก

    ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มีการอัปโหลดไฟล์ · กด ลบไฟล์ เพื่อเริ่มงานใหม่

สิ่งที่โปรแกรมทำ

ขั้นที่ 1 ตัด

  • เก็บบรรทัดแรก (PSKV…) ไว้เสมอ
  • เก็บตั้งแต่ B/L เริ่มต้นถึง B/L สุดท้าย รวม sub-B/L และบรรทัดตู้ของ B/L สุดท้าย
  • บรรทัดก่อนและหลังช่วงนี้ตัดออกทั้งหมด

ขั้นที่ 2 Change status

  • col 36-40 = POL เช่น VNSGN
  • col 41-45 และ 46-50 = THBKK
  • col 51-54 = Shed 0145 / 0122
  • col 844-845 = อักษร 2 ตัวแรกของ POL แทน TH
  • บรรทัดตู้ = Status ใหม่ เช่น 8 N → 9 N
  • หน่วยหีบห่อ PG → PX ทุก B/L

ความยาวบรรทัดและการขึ้นบรรทัด (CRLF) คงเดิมทุกไบต์ ไฟล์ต้นฉบับไม่ถูกแก้ไข

ใช้แบบโปรแกรมในเครื่อง (Python)

ครั้งแรกรัน pip install pandas xlrd openpyxl แล้ววางไฟล์ MMAN และไฟล์ Status ในโฟลเดอร์ input

python mman_vn.py HASLS21260801066 --to HASLS21260801762

ผลอยู่ที่ output\MMAN_VN.txt · ไม่ใส่ --to = เก็บถึงบรรทัดสุดท้าย

ถ้าเจอปัญหา

ข้อความ / อาการวิธีแก้
ไม่พบ B/L ที่ระบุตรวจเลข B/L เริ่มต้น/สุดท้ายว่ามีอยู่ในไฟล์ MMAN จริง
B/L ไม่อยู่ในรายการ / ไม่มี POLB/L นั้นไม่มีในไฟล์ Status ให้เพิ่มลงไฟล์ Status แล้วทำใหม่
ตำแหน่งคอลัมน์ผิดปกติไฟล์ MMAN อาจไม่ใช่รูปแบบมาตรฐาน ส่งไฟล์ให้ Rattana ตรวจ

ก่อนส่งไฟล์ ควรตรวจตารางผลการเปลี่ยนและตัวอย่างบรรทัดที่แก้ทุกครั้ง
