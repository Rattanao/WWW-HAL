Check CNTRS

Compares the carrier's MANIFEST with the CNTRS (Container List for Feeder) for every container, then produces a colour-coded CNTRS_EDI.xlsx report so any mismatch stands out before you file the declaration.

MANIFEST.xls+ CNTRS.xls / .pdf→ CNTRS_EDI.xlsx
Check online (no install) Download the program (ZIP) Open on GitHub

First-time setup

Once per computer, Windows (or use "Check online" above and install nothing at all)

  1. Install Python 3 from python.org/downloads

    On the installer's first screen tick ☑ Add python.exe to PATH before clicking Install Now

  2. Download the program with the "Download the program (ZIP)" button above

    Right-click the ZIP → Extract All, and keep the folder anywhere, e.g. Documents

  3. The first run needs an internet connection

    The program installs the libraries it needs (pandas, openpyxl, xlrd, pdfplumber) automatically

Every job

  1. Put the files in the input folder

    One MANIFEST (.xls/.xlsx) and at least one CNTRS (.xls/.xlsx or .pdf). File names don't matter: the program tells them apart by their content. You can add several CNTRS files at once (e.g. one per destination BMT/LCH/LKR) and the program merges them into one set

  2. Double-click run-check-cntrs.bat

  3. Open the result at output\CNTRS_EDI.xlsx

    The black window also summarises how many containers were found and how many don't match. If CNTRS_EDI.xlsx is open in Excel, the program saves under a new name (e.g. CNTRS_EDI_2.xlsx) instead of overwriting it

Reading the CNTRS_EDI.xlsx report

One row per container. MANIFEST and CNTRS columns sit side by side for every field. Matching cells just show "-"; mismatches show both actual values on a red background

Fields compared for every container

  • SHED NUMBER (compared as written + locked rules: DG = 2826 for destination THLCH only, BMT = 0110, Lat Krabang = 0332)
  • STATUS (FCL / LCL)
  • TEMP of reefer containers
  • VENT: reefers must always state it in the MANIFEST
  • DG CLASS / UN (the UN number is the main key)
  • REMARK by destination: BMT = BY BARGE, SCT = BY TRUCK, LKR = BY TRUCK (reefer/DG), otherwise BY TRAIN

Flagged red/yellow right away

  • Containers in CNTRS but missing from MANIFEST, or the reverse (critical rows)
  • SHED breaking the locked rule for its destination
  • Incomplete TRANSIT REMARK: it needs both the word TRANSIT and "TO <country>"
  • TEMP mismatch, or a reefer with no VENT
  • DG CLASS/UN mismatch

Troubleshooting

Message / symptomFix
Python not foundReinstall Python and tick Add python.exe to PATH
PermissionError: [Errno 13]CNTRS_EDI.xlsx is open in Excel. The program saves under a new name automatically, so nothing else is needed; or close the file and run again to get the original name back
MANIFEST / CNTRS file not foundCheck the files are in the input folder with a .xls/.xlsx or .pdf extension. The program identifies them by content, not by name
An unusually large number of mismatches (e.g. over half)Usually a new file layout with shifted columns. Send the file to Rattana so the program can support it

This report is a checking aid. Before filing, a person must always review every red or yellow cell
