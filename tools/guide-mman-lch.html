เครื่องมือแก้ไฟล์ EDI · MMAN

MMAN LCH

ตัดเก็บเฉพาะช่วง B/L ที่ต้องการ แล้ว Change Status ตามรายการในขั้นตอนเดียว ได้ไฟล์ MMAN_LCH.txt ทำงานในเบราว์เซอร์ ไม่มีการอัปโหลดไฟล์

MMAN_*.txt+STATUS .xls→MMAN_LCH.txt
ใช้งานออนไลน์ (ไม่ต้องติดตั้ง) เปิดหน้า GitHub

ขั้นที่ 1 ตัด

  • เก็บบรรทัดแรก (PSKV) เสมอ แล้วเก็บตั้งแต่ Start B/L ถึง End B/L (รวม sub-B/L …A, …B และบรรทัดตู้ของ B/L สุดท้าย) บรรทัดก่อนและหลังช่วงนี้ตัดออก
  • ว่างช่อง Start = ตั้งแต่ B/L แรก · ว่างช่อง End = ถึงบรรทัดสุดท้าย · ว่างทั้งสองช่อง = ไม่ตัด
  • หลังตัด ความยาวบรรทัดและการขึ้นบรรทัด (CRLF) คงเดิมทุกไบต์

ขั้นที่ 2 Change status (กับ B/L ที่เหลือ)

  • col 36-40 = POL (คอลัมน์ C) · col 41-45 = ท่าเรือของ B/L ส่วนใหญ่ในไฟล์ · col 46-50 = ท่าเรือตามต้นฉบับ คงเดิม
  • col 51-54 = Shed ตามท่าต้นฉบับ: BMT 0110 · SCT 0302 · LKR 0332 · UCT 0113 · THLCH DG 2826 · THBKK ที่ไป LAOS 0124 · ที่เหลือตามช่อง SHED NO.
  • col 844-845 = อักษร 2 ตัวแรกของ POL แทน TH · บรรทัดตู้ = Status จากคอลัมน์ B (เช่น 8  N → 9  N)
  • PG → PX ทุก B/L · ตัวอักษร O หน้า description (col 3804) → 5 เฉพาะ B/L ที่ Status 9  N
  • ชื่อ consignee / notify = ตามชื่อ notify ที่ col 1672 เว้นวรรค 1 เคาะ · ยกเว้น TRANSIT/TRANSHIPMENT คงเดิม และใส่ประเทศปลายทางที่ col 1670
